叠加介绍

系统介绍
  • 叠加系统可以让已激活的头像、头衔、称谓效果同时生效：先用「一键穿戴」道具激活背包内所有未拥有的头像 / 头衔 / 称谓，再在叠加界面把所有效果全部勾选，即可获得全部属性加成。
等级限制：头像叠加需人物等级达到 35 级；头衔 / 称谓叠加需人物等级达到 1 级。
头像叠加
等级限制：人物等级达到 35 级。
使用方法
  1. 前往金币商城，往下拉找到「便捷」板块中的「穿戴系列」，购买一个「一键‖穿戴头像」，使用后可一键激活背包内所有未拥有的头像。
  2. 点开右上角人物头像 → 点击头像 → 点击效果 → 点击叠加，把所有的都勾选上即可！
头衔叠加
等级限制：人物等级达到 1 级。
使用方法
  1. 前往金币商城，往下拉找到「便捷」板块中的「穿戴系列」，购买一个「一键‖穿戴头衔」，使用后可一键激活背包内所有未拥有的头衔。
  2. 点开右上角人物头像 → 点击信息 → 点击查看 → 查看属性 → 点击叠加，把所有的都勾选上即可！
称谓叠加
等级限制：人物等级达到 1 级。
使用方法
  1. 前往金币商城，往下拉找到「便捷」板块中的「穿戴系列」，购买一个「一键‖穿戴称谓」，使用后可一键激活背包内所有未拥有的称谓。
  2. 点开右上角人物头像 → 点击信息 → 点击查看 → 查看属性 → 点击叠加，把所有的都勾选上即可！
