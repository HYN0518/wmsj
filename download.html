安卓下载教程

  1. 复制下载链接到浏览器打开，下载时选择"原安装包下载"，不要选择"应用市场下载"

  2. 遇到报毒是不用管，可以适当减低手机自身的安全防护，咱们的都是没有毒属于误报

    ⚠️ 安全提示：游戏安装包可能被误报为病毒，请确认来源可靠后继续安装

  3. 在安装时，要选择"继续安装"，部分机型会提示"查找类似应用"不要这个，要继续安装

注：安卓和鸿蒙系统下载方式一致，不过多阐述

方法二：通过 QQ 获取 APK 文件

  1. 找各群群主 / 管理或小助理要她的 QQ 私发你 APK 文件或群文件下载

  2. 该方法下载下来后 APK 后缀会带.1（例：base.apk.1）

  3. 右键文件，选择重命名，将.1删除

IOS / iPad 系统安装教程（图文）

  1. 将链接复制到浏览器打开，点击"苹果下载"

  2. 会自动弹出下载描述文件，点击允许

  3. 打开"设置"，点击"通用"，下拉找到"VPN与设备管理"，打开下载好的描述文件并安装

  4. 安装描述文件，安装时输入的密码为锁屏密码

  5. 安装好后点击"更多详细信息"

  6. 查看数字密钥后返回浏览器输入获得的密钥

  7. 点击开始下载，等待即可

IOS / iPad 系统 VPN 教程

  1. 首先打开手机/平板的设置

  2. 找到通用选项

  3. 找到VPN与设备管理

  4. 点击"信任"选项

📌 系统版本高的设备要求必须重启手机才可以，低的版本直接允许即可！

爱思助手官网：https://www.i4.cn/

对于不能上架 App Store 的应用，可以使用证书签名或使用 Apple ID 签名后正常安装到设备。准备好 Apple ID 以及需要签名的 IPA 文件，使用爱思助手就可以快速完成签名。

使用 Apple ID 签名

适用于开发者或普通用户免费使用 Apple ID 进行签名，签名的有效期为 7 天。

点击这里查看 IPA 签名功能常见问题

使用 Apple ID 签名方法：

  1. 在爱思助手"工具箱"中打开"IPA 文件签名"

  2. 点击"添加 IPA 文件"选择需要签名的 IPA 文件

  3. 选择"使用 Apple ID 签名" → "添加 Apple ID"，随后输入用于签名的 Apple ID、密码并选择或输入对应设备的设备标识（指签名后 IPA 文件要安装的设备）

  4. 检查无误后点击"确定"。建议操作前需要将 iOS 设备连接至爱思助手，并保证可以读出"设备标识"

  5. 添加需要签名的 IPA 文件并勾选 IPA 文件和用于签名的 Apple ID，点击"开始签名"即可

  6. 签名成功后通过爱思助手安装该应用。安装完成后，首次打开前记得去"设置 - 通用 - 描述文件"内信任该应用

📌 说明：使用开启了双重认证的 Apple ID 签名 IPA 包后 iCloud 会多出一台 iMac 27 寸、系统版本为 10.15.6 的记录，这个不必担心，Apple ID 签名时需要模拟请求登录苹果服务器，申请证书和描述文件，登录过苹果服务器 iCloud 就会有登录记录。
⚠️ 请务必注意，已签名的 IPA 文件和原文件保存路径可能并不相同，签名后应该点击"签名文件保存到"→"打开"按钮，可用于安装的已签名 IPA 文件都会储存在该目录下，请注意分辨。
